개인정보 처리방침

via robo(이하 '회사')는 테일러 트립 앱(이하 '앱')을 이용하는 분의 개인정보를 「개인정보 보호법」에 따라 처리합니다. 앱은 회원가입 없이 익명으로 쓰도록 만들어져 이름, 전화번호, 이메일 같은 정보를 받지 않습니다.

시행일: 2026년 11월 27일

1. 처리하는 정보

  • 자동으로 만들어지는 정보: 익명 사용자 ID, 로그인 유지용 인증 정보, 계정을 만든 일시와 최근 접속 일시, 서버 접속 기록(IP 주소 등)
  • 직접 입력하실 때만 저장되는 정보:
    • 입맛 프로필: 매운맛·짠맛·현지식 선호도(1~5)
    • 리뷰: 장소, 방문일, 항목별 별점, 후기, 협찬 여부
    • 영수증·티켓 사진(방문 인증을 원하실 때): 기기에서 크기를 줄이고 사진 속 위치정보(EXIF)를 지운 뒤 비공개 저장소에 올립니다
    • 가격 일치 제보: 판매처, 노선, 가격이 같았는지 여부
    • 새로 등록한 장소 이름
    • 저장한 여행 계획(서버 백업)
  • 이용 기록: 포인트 적립·사용 내역, '나만의 여행 비서' 이용권
  • 기기에만 저장되는 정보(회사가 받지 않음): 여행 조건과 검색 결과 캐시, 알림에서 고른 방문 순서, 여행 비서 알림 예약
  • 앱은 기기 위치(GPS), 연락처, 전화번호, 광고 식별자를 수집하지 않으며, 광고·분석 도구를 쓰지 않습니다. 사진은 영수증 인증을 위해 직접 고르신 한 장만 다룹니다.

2. 처리 목적

  • 여행 계획 저장과 백업, 여행지 현지 시각에 맞춘 알림
  • 리뷰 게시, 방문 인증 확인, 나와 입맛이 비슷한 여행자 평균 계산
  • 포인트 적립·사용과 부정 적립 방지(계정별 적립 한도, 별점 몰림 확인)
  • 판매처별 가격 일치율 계산(개별 제보는 공개하지 않고 집계만 사용)
  • 문의 응대, 서비스 안정성 확보

3. 공개되는 정보

리뷰의 별점·후기·방문일, 작성 당시의 입맛 프로필과 계정 생성 시점은 다른 이용자에게 공개됩니다. 작성자 ID와 영수증 사진은 공개되지 않습니다.

4. 보유 및 이용 기간

  • 익명 계정과 연결된 정보: 앱에서 '내 데이터 삭제'를 누르실 때까지 보관하고, 누르시면 바로 지웁니다.
  • 저장한 여행·리뷰·포인트가 하나도 없는 익명 계정: 만든 지와 마지막으로 쓴 지 30일이 지나면 자동으로 지웁니다.
  • 영수증·티켓 사진: 운영자 확인이 끝난 날부터 30일 안에 지웁니다. 리뷰가 지워지면 연결된 사진도 하루 뒤 지웁니다.
  • 서버 접속 기록: 서버 운영사가 보안과 장애 대응을 위해 짧은 기간 보관한 뒤 지웁니다.
  • 관계 법령에서 보관을 요구하는 경우 그 기간 동안 보관합니다.

5. 제3자 제공과 외부 사이트 이동

회사는 이용자의 정보를 제3자에게 제공하지 않습니다. 앱에서 항공권·숙소·투어 링크를 누르면 해당 판매처 사이트로 이동하며, 이때 회사의 제휴 식별값만 함께 전달되고 이용자의 정보는 전달되지 않습니다. 이동한 사이트에서의 예약·결제와 개인정보 처리는 그 사이트의 방침을 따릅니다.

6. 개인정보 처리의 위탁

  • Supabase Inc.: 데이터 저장, 익명 로그인, 영수증 사진 보관, 서버 함수 운영 (데이터 저장 위치: 대한민국 서울 리전)

항공 가격, 날씨, 환율 정보는 회사 서버가 외부 정보 제공처에서 받아 오며, 이 과정에서 이용자의 정보는 전달하지 않습니다.

7. 개인정보의 국외 이전

데이터는 대한민국(서울) 리전의 서버에 저장되지만, 서버 운영사의 기술 지원 과정에서 국외에서 접근될 수 있어 다음과 같이 알려 드립니다.

  • 이전받는 자: Supabase Inc. (미국, privacy@supabase.io)
  • 이전 국가: 미국 등 Supabase Inc.의 지원 인력 소재 국가
  • 이전 항목: 1항의 정보 중 서버에 저장되는 정보
  • 이전 일시와 방법: 앱 이용 시 네트워크를 통해 암호화 전송
  • 이용 목적과 보유 기간: 서버 운영·장애 대응, 4항의 보유 기간과 같음
  • 거부 방법: 앱 이용을 멈추고 '내 데이터 삭제'를 누르시면 됩니다. 이 경우 서버 저장 기능을 이용할 수 없습니다.

8. 만 14세 미만 아동

앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만 아동의 정보가 저장된 사실을 알게 되면 지체 없이 지웁니다.

  • 열람, 정정, 처리 정지 요청이나 앱을 이미 지우신 경우의 삭제 요청은 ko.2580.pp@gmail.com 또는 문의 게시판으로 보내 주세요. 자세한 방법은 데이터 삭제 안내에 있습니다.
